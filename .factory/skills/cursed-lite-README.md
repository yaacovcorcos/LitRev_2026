# Cursed Lite Skills (Internal)

This repo includes internalized, safer adaptations of selected cursed-plugins skills.

Included skills:
- `cursed-lite-ship-ritual`
- `cursed-lite-obituary`
- `cursed-lite-agent-repellent`

Intent:
- keep the humor and narrative utility,
- remove social sharing and vendor promo,
- avoid contributor targeting,
- keep outputs advisory and non-blocking.

Use these as optional retrospective and readiness prompts, never as merge/deploy gates.

See `docs/runbooks/external-pattern-intake.md` for the promotion rule: repeated useful findings must become normal LitRev rules, tests, runbooks, or owner-plan updates.
