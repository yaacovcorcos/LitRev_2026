# File Index

A living index of files and folders in the repository with one-line descriptions.

## Root Directory
- `.claude/`: Claude workspace metadata.
- `.factory/`: Factory workspace metadata.
- `.vercel/`: Vercel project configuration (local).
- `AGENTS.md`: Agent guidelines for contributors.
- `AI_MEMORY_IMPLEMENTATION_PLAN.md`: Memory system plan/spec (may be superseded by schema).
- `DB_ARCHITECTURE.md`: Database schema overview and storage strategy.
- `FILE_INDEX.md`: This index.
- `GLOSSARY.md`: Definitions of key terms.
- `MEMORY_LESSONS.md`: Memory principles and rules for LitRev.
- `PRD.md`: Product requirements and status (single source of truth).
- `next_tasks.md`: Current task list and near‑term roadmap.
- `planB`: Backend implementation plan and phase status.
- `secrets.local.md`: Local secrets (gitignored).
- `mcp.json`: MCP server definitions for shared agents.
- `next-app/`: Next.js application workspace.

- `.env`: Runtime database envs (gitignored).
- `.env.local`: Local app envs (gitignored).

- `.vercel/`: Vercel project config (local).

- `app/`: Next.js App Router pages and server actions.
- `components/`: React UI components.
- `contexts/`: React context providers.
- `data/`: Static data and mock content.
- `lib/`: Client and server libraries (includes AI services).

- `public/`: Static assets.
- `scripts/`: Local scripts/utilities.
- `styles/`: Global styling tokens and base styles.
- `types/`: Shared TypeScript interfaces.
- `package.json`: NPM scripts and dependencies.
- `next.config.ts`: Next.js configuration.
- `tsconfig.json`: TypeScript configuration.
- `eslint.config.mjs`: ESLint configuration.
